# rerep — Nepal land search

Live site: https://ayushsubedi.github.io/rerep/

A personal screening tool for Nepali land listings: unit-safe prices (aana, ropani, kattha, dhur), comparables, and a
cited, factor-by-factor X-Ray for each listing. **Screening tool, not advice**: check the lalpurja, the napi naksa, a visit
with the neighbours and the current malpot rate before paying anything.

Listings come from public classifieds portals and each links back to the original ad. Phone numbers, seller names,
photos and descriptions are not republished. Boundaries: Survey Department of Nepal via UN OCHA / HDX (CC BY-IGO);
places: GeoNames (CC BY 4.0); map tiles: OpenStreetMap contributors; Leaflet (BSD-2); fonts Orbitron and Share Tech Mono (OFL).

This repository holds only the generated static site. The crawler and database run locally.
